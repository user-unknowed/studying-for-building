  1. ① JavaSE 基础 → 01 章 + javase-demo（字节码、类型陷阱、OOP、集合、并发、现代语法）
  2. ② Java × SQL 融合 → 02 章 + java-sql-demo（JDBC、注入攻防、转账事务、批处理）
  3. ③ SQL 工业实践 → 03 章 + sql-demo（窗口函数、EXPLAIN、索引、MVCC）
  4. ④ JavaEE 服务端 → 05 章 + demos（先原生 Jakarta EE，后 Spring Boot）
  5. ⑤ 上位机 / 工业采集 → 06、07 章 + demos（先桌面版 device-monitor，再网页版 web-monitor）
  6. ⑥ Python 与 AI 大模型 → 08 章 + py-ai-demo（张量、Autograd、手写 MiniGPT、GPU 并行、vLLM 服务化）
  7. ⑦ 竞赛备赛（华为ICT大赛·云赛道） → 09 章（赛制赛程、考点地图、分阶段计划，衔接 03 章 SQL 与 08 章 AI 基础）

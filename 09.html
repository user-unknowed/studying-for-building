1. 华为ICT大赛是什么

1.1 主办方与历史

华为ICT大赛是华为公司自 2015 年起主办的、面向全球高校师生的年度 ICT 赛事，定位为国际化竞技和交流平台。

  • 规模：截至第十届（2025-2026）累计报名 118 万人以上，覆盖院校 2000+、国家和地区 100+。第十届单届报名 22 万余人，中国区 15.4 万人为最大赛区。
  • 认可度：在中国被纳入《全国普通高校大学生竞赛项目榜单》；在海外被纳入 UNESCO 全球技能学院关键伙伴旗舰项目。
  • 当前赛季：第十一届（2026-2027）已于 2026 年 9 月启动报名。

1.2 七大赛事体系

第十一届大赛设七大赛事，其中学生可报名的主力是实践赛：

赛事 面向 核心考察

编程赛 仅中国 仓颉语言特性与工程应用

根据第十一届高校官方通知，网络赛项涵盖四大技术方向：

3. 路由器与交换机：通俗原理

这是网络赛道最核心的基础概念。用最通俗的方式讲清楚。

3.1 交换机：同一个小区里的快递员

一句话定义：交换机负责在同一个局域网（同一个网段）内把数据准确送到目标设备。

打比方：想象一个小区，每栋楼、每户人家都有门牌号（MAC 地址）。快递员（交换机）记住每个门牌号对应哪一户，包裹来了直接送到对的人家，不会挨家挨户敲门。

核心工作机制：

  1. 学习 MAC 地址：交换机收到一个数据帧，会把源 MAC 地址和接收端口记录到 MAC 地址表
  2. 转发决策：查目标 MAC 地址在表里有没有记录 - 有 → 只从对应端口发出去（单播） - 没有 → 从除接收端口外的所有端口发出去（泛洪）
  3. 二层转发：工作在 OSI 第二层（数据链路层），只看 MAC 地址，不看 IP

交换机的关键能力：

能力 作用
MAC 地址学习 自动建立端口-MAC 映射
单播转发 精确投递，不干扰其他端口
广播隔离（VLAN） 把一个大网络逻辑隔成多个小网络
环路防止（STP） 自动阻断冗余链路，防止广播风暴

3.2 路由器：不同城市之间的邮局

一句话定义：路由器负责在不同网络之间选择最佳路径，把数据送到目的地。

打比方：你从北京寄信到上海，邮局（路由器）不关心你在北京市内怎么走，只负责选一条北京到上海的最佳路线（高铁或飞机）。路由器就是网络世界的"邮局分拣中心"。

核心工作机制：

  1. 查路由表：路由器收到一个 IP 数据包，根据目标 IP 查路由表
  2. 最长前缀匹配：选择掩码最长的匹配条目（最精确的路由）
  3. 转发到下一跳：把数据包从对应接口发出去，交给下一个路由器或目标网络
  4. 三层转发：工作在 OSI 第三层（网络层），看 IP 地址

路由器的关键能力：

能力 作用
路由选择 用 OSPF/BGP 等协议动态学习最优路径
网络互联 连接不同网段/不同网络
广播域隔离 不转发二层广播包，控制广播范围
ACL/NAT 访问控制、地址转换（安全与共享上网）

3.3 两者区别速记

对比项 交换机 Switch 路由器 Router
工作层次 第二层（数据链路层） 第三层（网络层）
寻址依据 MAC 地址 IP 地址
作用范围 同一局域网内 不同网络之间
关键表 MAC 地址表 路由表
转发方式 二层交换（硬件转发，快） 三层路由（查路由表）
比喻 小区快递员 城际邮局
典型设备 华为 S 系列交换机 华为 AR 系列路由器

3.4 一张图理解数据流向

PC1 ──┐                                         ┌── PC3
      ├── [交换机A] ── [路由器] ── [交换机B] ──┤
PC2 ──┘    (同VLAN内    (不同网段间     (同VLAN内   ├── PC4
            直接转发)     选路转发)      直接转发)
  • PC1 发给 PC2：只走交换机A，不需要路由器（同网段）
  • PC1 发给 PC3：交换机A → 路由器 → 交换机B（跨网段，必须经过路由器）

3.5 三层交换机：快递员兼邮局分拣员

现代网络中还有三层交换机——它把交换机的二层转发和路由器的三层路由功能合二为一，常用于企业网核心层。它的路由转发由 ASIC 硬件完成，比传统路由器的 CPU 转发快得多。比赛中常考三层交换机做 VLAN 间路由。

4. 核心知识点详解

4.1 VLAN：把一个大网络切成多个小网络

为什么需要 VLAN：一个大交换机下所有设备在同一个广播域，广播包泛滥、安全无法隔离。VLAN 把交换机逻辑上分成多个"虚拟局域网"。

三种端口类型：

端口类型 收发数据时 典型用途
Access 只能属于一个 VLAN，收发不带标签的数据 连接终端（PC、打印机）
Trunk 允许多个 VLAN 通过，收发带 802.1Q 标签的数据 交换机之间互联
Hybrid 灵活配置哪些 VLAN 带标签、哪些不带 华为特有，灵活组网

VLAN 间路由：不同 VLAN 之间默认不能通信，需要三层设备（路由器或三层交换机）做单臂路由或 VLANIF 接口。

# 华为 VRP 配置示例：创建 VLAN 并配置 Access 端口
system-view
vlan 10
 name DEPT-SALES
quit
interface GigabitEthernet 0/0/1
 port link-type access
 port default vlan 10
quit

4.2 STP/MSTP：防止环路又保留冗余

问题：交换机之间接两条线做冗余，会形成环路，导致广播风暴、MAC 地址表震荡。

STP（生成树协议）：逻辑上阻断一条链路，物理上保留冗余；当主链路故障时，自动放开备份链路。

MSTP（多生成树）：华为设备默认使用，支持 VLAN 负载分担——不同 VLAN 走不同的生成树实例，充分利用冗余链路。

端口状态：Disabled → Blocking → Listening → Learning → Forwarding

4.3 OSPF：动态路由协议的主力

OSPF（开放式最短路径优先）是链路状态路由协议，用 SPF 算法计算最短路径。比赛中单区域 OSPF 是必考点。

核心概念： - Router ID：路由器在 OSPF 域中的唯一标识（通常用环回口 IP） - 区域 Area：单区域用 Area 0（骨干区域） - 邻居关系：通过 Hello 包发现邻居，建立邻接后同步 LSDB（链路状态数据库） - 度量值 Cost：基于带宽，越小越优

# 华为 VRP 配置示例：单区域 OSPF
system-view
interface LoopBack 0
 ip address 1.1.1.1 255.255.255.255
quit
ospf 1 router-id 1.1.1.1
 area 0
  network 192.168.1.0 0.0.0.255
  network 1.1.1.1 0.0.0.0
 quit
quit

4.4 静态路由与默认路由

静态路由：管理员手动指定的路由，简单可靠，但不适应拓扑变化。

ip route-static 192.168.2.0 255.255.255.0 192.168.1.2
#                目标网络        掩码          下一跳

默认路由：0.0.0.0 0.0.0.0，当路由表没有更精确的匹配时使用，常用于连接 ISP 的出口。

4.5 ACL：访问控制列表

基本 ACL（2000-2999）：只匹配源 IP 地址 高级 ACL（3000-3999）：匹配源/目的 IP、协议、端口号

# 高级 ACL：禁止 192.168.1.0 网段访问服务器的 80 端口
acl number 3000
 rule 5 deny tcp source 192.168.1.0 0.0.0.255 destination 10.0.0.1 0 destination-port eq 80
 rule 10 permit ip
quit
interface GigabitEthernet 0/0/1
 traffic-filter inbound acl 3000
quit

4.6 NAT：网络地址转换

让内网多个设备共享一个公网 IP 上网。

类型 用途
静态 NAT 一对一固定映射（服务器对外发布）
动态 NAT 地址池多对多
NAPT（PAT） 多对一，用端口号区分（最常用）

4.7 网络安全：防火墙与 VPN

  • 华为防火墙（USG 系列）：安全区域（Trust/Untrust/DMZ）、安全策略、会话表
  • IPSec VPN：用加密隧道在公网上安全传输数据，适合站点间互联
  • SSL VPN：远程接入，用浏览器即可，适合移动办公

4.8 WLAN：无线局域网

组网架构：AC（无线控制器）+ Fit AP（瘦 AP） - AC 负责集中管理、配置下发、用户认证 - AP 负责射频信号收发

关键配置：AP 上线、SSID 创建、安全模板（WPA2/WPA3）、VLAN 绑定。

5. 实验环境：eNSP 入门

5.1 eNSP 是什么

eNSP（Enterprise Network Simulation Platform）是华为官方推出的网络模拟器，网络赛道全球总决赛指定使用。可以模拟华为路由器、交换机、防火墙、PC 等设备，支持真实 VRP 命令行。

5.2 常用设备

设备 型号 用途
路由器 AR2220 路由、广域网、NAT、VPN
交换机 S5700 / S3700 VLAN、STP、链路聚合、三层交换
防火墙 USG6000V 安全策略、NAT、VPN
PC/Server - 测试连通性、跑服务
AC/AP AC6005 / AP WLAN 实验

5.3 基本操作流程

  1. 拖入设备 → 连线（注意接口类型）
  2. 启动设备 → 等待 VRP 启动
  3. 双击设备进入命令行
  4. 配置 → 用 display 命令验证 → 用 PC ping 测试连通性

5.4 常用 display 命令

display current-configuration    # 查看当前配置
display ip routing-table         # 查看路由表
display mac-address              # 查看 MAC 地址表
display vlan                     # 查看 VLAN
display ospf peer                # 查看 OSPF 邻居
display stp                      # 查看生成树状态
display interface brief          # 查看接口简要
display acl all                  # 查看所有 ACL

5.5 排障思路（比赛关键能力）

网络配不通时，按层排查：

  1. 物理层：接口是否 up？display interface brief 看状态
  2. 链路层：VLAN 是否正确？Trunk 是否放通？display vlan、display port vlan
  3. 网络层：IP 配置是否正确？路由是否存在？display ip routing-table
  4. 协议层：OSPF 邻居是否建立？display ospf peer
  5. 安全层：ACL/防火墙策略是否拦截？display acl、查看会话

比赛拉开差距的不是"会不会配"，而是"配不通时能不能快速定位原因"。

6. 备赛最大难点与突破策略

6.1 最大难点：广度与深度的矛盾

结合比赛实际，网络赛道备赛的核心难点是"知识面广 + 实践要求高 + 团队协作紧"：

难点 具体表现
知识点覆盖极广 数通、DCN、安全、WLAN 四大方向，每个方向数十个知识点，一人难全部精通
实验操作要求高 全球总决赛 8 小时综合实验，一个协议配错可能整网不通
理论实操结合紧 既要过理论笔试，又要把理论落地到配置
团队分工难 3 人 8 小时协同，分工不清浪费大量时间
排障压力大 限时环境下网络不通，容易慌乱

6.2 突破策略

策略一：分工专攻，交叉覆盖 - 3 人按方向分工：1 人主攻数通路由，1 人主攻交换与 DCN，1 人主攻安全与 WLAN - 每人把自己方向练到熟练，同时了解其他方向基础，便于协作

策略二：以练代背，肌肉记忆 - 每个知识点配 1-2 个小实验验证，做到"理解 + 会配" - 核心协议（VLAN、OSPF、STP、ACL）反复练到不看资料也能配

策略三：整网实战，刻意排障 - 用往届真题做整网实验，从拓扑设计到完整配置走全流程 - 每次实验后复盘：哪里配错、哪里耗时、排障思路是否清晰 - 刻意制造故障练习排障（故意配错一个点，队友排查）

策略四：限时模拟，建立节奏 - 严格按 8 小时限时做整套实验 - 建立团队协作 SOP：谁搭骨干、谁配接入、谁做安全

7. 分阶段备赛计划

第一阶段：打基础（4-6 周）

  • 对照 HCIA-Datacom 大纲，逐个过知识点
  • 每个知识点配 eNSP 小实验
  • 产出：一张完整的知识网络图 + 每个核心协议的配置模板

第二阶段：专项突破（4-6 周）

  • 按团队分工，每人主攻一个方向
  • 做 HCIP 级别的进阶内容（OSPF 多区域、BGP、路由策略、IPSec VPN）
  • 每周一次团队整合实验

第三阶段：整网实战（4 周）

  • 用往届真题和模拟题做完整实验
  • 每次实验严格限时，赛后详细复盘
  • 建立排障手册：常见故障现象 → 排查命令 → 解决方法

第四阶段：冲刺模拟（2-3 周）

  • 完全模拟全球总决赛节奏：8 小时、全英文题、只允许官方文档
  • 打磨团队协作 SOP，形成肌肉记忆
  • 查漏补缺，回归基础知识点

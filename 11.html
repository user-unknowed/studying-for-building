1. 网络是怎么传输的（视频 P1）

📺 网络是怎么传输的？（12:19）
▶ 在 B 站观看 P1 →
UP 主：飞天闪客 · 动画科普 · 第 1 集 · 时长 12:19

从拆快递的比喻讲起，把包交换、IP/MAC/端口、路由跳转、TTL、ARP 等数通基础概念串成一条完整的数据传输链路。

1.1 视频要点提炼

  • 包交换（Packet Switching）：数据被切成一个个小"包"独立发送，到了再拼回去——像拆快递寄包裹，不用一整车拉。
  • IP 地址（网络层 L3）：逻辑地址，决定包最终要到哪里去（像收件地址）。
  • MAC 地址（数据链路层 L2）：物理地址，决定下一跳交给谁（像快递站之间转运）。
  • 端口号（传输层 L4）：标识应用进程（像门牌号），HTTP=80、HTTPS=443。
  • 路由跳转：路由器查路由表决定包往哪个接口转发，一跳一跳接力到目的地。
  • TTL（Time To Live）：每过一跳减 1，归零丢弃——防止包在网络里无限循环。
  • ARP：已知 IP 查 MAC，用于同一网段内的实际交付。

1.2 对应网络赛道考点：数通基础

这一集覆盖了 HCIA-Datacom 认证的第一章"数据通信基础"：OSI 七层模型、TCP/IP 协议栈、IP 地址与子网划分、ARP 工作原理。ICT 网络赛道实践赛的配置题第一步几乎都是"给接口配 IP"，理解 IP/掩码/网关是后续一切配置的前提。

1.3 eNSP 实操：路由器接口 IP 与静态路由

在 eNSP 里拖两台 AR2220 路由器（R1、R2），用线连起 G0/0/0 接口，双击 R1 进入命令行。下面这组命令完成"配接口 IP + 写静态路由 + 查路由表"全流程：

🔧 eNSP Lab 1 · R1 上的接口配置与静态路由
 1system-view                          # 进入系统视图（全局配置模式）
 2sysname R1                            # 给路由器命名为 R1，便于识别
 3interface GigabitEthernet0/0/0        # 进入千兆以太网接口 0/0/0 视图
 4ip address 192.168.1.1 24             # 配置 IP：192.168.1.1/24（24 = 255.255.255.0）
 5undo shutdown                         # 确保接口开启（eNSP 默认开启，生产环境可能关闭）
 6quit                                  # 退回系统视图
 7ip route-static 10.0.0.0 255.0.0.0 192.168.1.2  # 静态路由：去 10.0.0.0/8 下一跳 192.168.1.2
 8display ip routing-table              # 查看完整路由表，验证静态路由是否生效
 9display ip interface brief            # 速览所有接口 IP 与物理/协议状态
10save                                  # 保存配置（否则设备重启后丢失）

关键理解：ip route-static 目的网段 掩码 下一跳 是网络赛道最基础的考题——告诉路由器"去这个网段的包，交给下一个路口的谁"。配完后 R2 也要反向配一条回程路由，否则 ping 不通（单向能去，回不来）。

2. 网络是怎么可靠的（视频 P2）

📺 网络是怎么可靠的？（08:55）
▶ 在 B 站观看 P2 →
UP 主：飞天闪客 · 动画科普 · 第 2 集 · 时长 08:55

从打电话讲起，把 TCP 三次握手、序列号确认、超时重传、校验和，以及 OSPF 路由协议的自动收敛串成一条可靠传输链路。

2.1 视频要点提炼

  • TCP 三次握手：SYN → SYN-ACK → ACK，双方确认收发能力后才传数据。
  • 序列号与确认号：每个字节有序号，接收方回确认号告诉对方"我收到哪了"，保证有序不丢。
  • 超时重传：发了之后等确认，超时没等到就重发——网络丢包不慌。
  • 校验和：头部+数据算个校验值，对方重算比对，不一致就丢——防传输途中的位翻转。
  • OSPF 路由协议：路由器之间自动交换链路状态，拓扑变了自动重新算路——比静态路由更可靠。
  • 收敛（Convergence）：网络拓扑变化后，所有路由器重新算路并达到一致稳定状态的过程。

2.2 对应网络赛道考点：可靠性与路由协议

HCIA-Datacom 的"IP 路由基础"与"OSPF 协议"章节直接对应本集。网络赛道实践赛高频考 OSPF——单区域配置、反掩码写法、Router-ID 指定、邻居关系查看。视频讲的"自动收敛"在比赛排障题里就是"为什么这条 OSPF 路由学不到"的排查思路。

2.3 eNSP 实操：OSPF 单区域配置

沿用 Lab 1 的两台路由器拓扑，把静态路由换成 OSPF，让两台路由器自动学习对方网段。双击 R2 进入命令行：

🔧 eNSP Lab 2 · R2 上启动 OSPF 并宣告网段
 1system-view                           # 进入系统视图
 2sysname R2                            # 命名 R2
 3interface GigabitEthernet0/0/0
 4ip address 10.1.1.2 24               # 配接口 IP
 5quit                                  # 退回系统视图
 6ospf 1 router-id 10.1.1.2            # 启动 OSPF 进程 1，手动指定 Router-ID
 7area 0                                # 进入骨干区域 0（单区域 OSPF 必须用 area 0）
 8network 10.1.1.0 0.0.0.255            # 宣告 10.1.1.0/24（OSPF 用反掩码 0.0.0.255）
 9network 192.168.1.0 0.0.0.255         # 宣告 192.168.1.0/24
10quit                                  # 退回系统视图
11display ospf peer brief               # 查看邻居摘要（Full = 邻居关系建立成功）
12display ospf routing                  # 查看 OSPF 计算出的路由
13display ip routing-table protocol ospf # 路由表中只看 OSPF 协议路由
14save                                  # 保存配置

关键理解：network 网段 反掩码 里的反掩码是重点——掩码 255.255.255.0 对应反掩码 0.0.0.255，比赛里写错掩码是常见扣分点。配完后两台路由器都宣告各自网段，OSPF 自动算路，display ospf peer brief 看到 Full 状态就成功了。

3. 网络是怎么安全的（视频 P3）

📺 网络是怎么安全的？（07:58）
▶ 在 B 站观看 P3 →
UP 主：飞天闪客 · 动画科普 · 第 3 集 · 时长 07:58

从小区门禁讲起，把防火墙、ACL、安全区域、访问控制、攻击防御串成一条网络安全防线。

3.1 视频要点提炼

  • 防火墙：在不同安全区域之间检查并过滤流量——像小区大门的保安。
  • ACL（访问控制列表）：一组 permit/deny 规则，按顺序匹配，命中即执行。
  • 五元组匹配：源 IP、目的 IP、源端口、目的端口、协议——高级 ACL 可精确到这个粒度。
  • 安全区域：Trust（内网可信）、Untrust（外网不可信）、DMZ（对外服务区）——区域间默认阻断。
  • 默认拒绝：ACL 末尾隐含一条 deny all，没显式 permit 的流量都会被拒绝。
  • 攻击防御：抗 DDoS、防端口扫描、入侵检测——网络安全的高阶能力。

3.2 对应网络赛道考点：安全

HCIA-Datacom 的"ACL 与安全"章节对应本集。网络赛道实践赛常考"用 ACL 限制某网段访问某服务"——比如禁止研发部访问生产库。高级 ACL（3000-3999）能匹配五元组，是比赛标配。视频讲的"默认拒绝"是排障题的常见坑：规则没写 permit ip，结果全断了。

3.3 eNSP 实操：ACL 访问控制

在 R1 上配一条高级 ACL：禁止 192.168.2.0/24 网段访问 10.0.0.0/8 的 80 端口（HTTP），其余放行。在 R1 命令行操作：

🔧 eNSP Lab 3 · R1 上配置高级 ACL 并应用到接口
 1system-view                           # 进入系统视图
 2acl 3000                              # 创建高级 ACL（3000-3999，可匹配源/目的/端口/协议）
 3rule 5 deny tcp source 192.168.2.0 0.0.0.255 destination 10.0.0.0 0.255.255.255 destination-port eq 80
 4                                      # 规则 5：禁止 192.168.2.0/24 访问 10.0.0.0/8 的 80 端口(HTTP)
 5rule 10 permit ip                     # 规则 10：放行其它所有 IP 流量（ACL 默认拒绝）
 6quit                                  # 退回系统视图
 7interface GigabitEthernet0/0/1        # 进入需要应用 ACL 的接口
 8traffic-filter outbound acl 3000     # 在出方向应用 ACL 3000（控制从该接口出去的流量）
 9quit
10display acl 3000                      # 查看 ACL 3000 规则配置与命中次数
11display traffic-filter user-defined   # 查看接口上的流量过滤应用情况
12save                                  # 保存配置

关键理解：traffic-filter outbound acl 3000 把 ACL 绑到接口出方向——比赛题常考"入方向 vs 出方向"的区别：在靠近源的接口入方向过滤能省路由器转发开销。规则编号（5、10）决定匹配顺序，编号小的先匹配。

4. eNSP 模拟器上手指南

4.1 下载安装与拓扑搭建

eNSP（Enterprise Network Simulation Platform）是华为官方出品的网络模拟器，免费但需注册华为账号。它模拟真实的 VRP（Versatile Routing Platform）系统，敲的命令和真机一模一样。

  • 下载：访问华为官网搜索"eNSP"，登录华为账号后下载安装包（仅支持 Windows）。
  • 依赖：安装时会提示装 WinPcap、Wireshark、VirtualBox，全选装上（eNSP 靠 VirtualBox 跑路由器镜像）。
  • 建拓扑：打开 eNSP → 新建拓扑 → 从左下"设备"栏拖路由器（推荐 AR2220）、PC、交换机到画布 → 用"连线"工具连接口 → 点绿色播放键启动设备。
  • 进命令行：双击路由器图标 → 弹出窗口点"命令行"标签页 → 看到 <Huawei> 提示符就能敲命令了。

4.2 VRP 命令视图速查

华为 VRP 是分层视图系统，不同视图能敲的命令不同。这张速查表帮你分清"现在在哪、能干啥"：

📋 VRP 命令视图层级速查
 1<Huawei>                              # 用户视图：开机默认，只能查看不能配置
 2system-view                           # 输入此命令进入系统视图
 3[Huawei]                              # 系统视图：可做全局配置（命名、路由、ACL 等）
 4[Huawei] interface GigabitEthernet0/0/0  # 进入接口视图
 5[Huawei-GigabitEthernet0/0/0]         # 接口视图：配 IP、开关接口
 6[Huawei-GigabitEthernet0/0/0] quit     # 退回系统视图
 7[Huawei] ospf 1                        # 进入 OSPF 协议视图
 8[Huawei-ospf-1]                        # 协议视图：配区域、宣告网段
 9[Huawei-ospf-1] quit
10[Huawei] return                        # 直接退回用户视图（快捷键 Ctrl+Z 同效）
11<Huawei> display ip routing-table     # 用户视图下用 display 查看各种信息

核心规律：system-view 往里进一层，quit 退一层，return（或 Ctrl+Z）直接退回用户视图。配置命令只能在系统视图及更深层敲，display 系列在任何视图都能用。

5. 网络赛道赛题类型与备赛策略

5.1 赛题类型

题型说明对应本章
配置题给拓扑图和需求，敲命令完成路由/ACL/协议配置Lab 1-3 的实操命令
排障题给一个配错的环境，用 display 系列排查并修复各 display 命令 + 常见坑（反掩码/默认拒绝）
综合设计题从需求文档出发设计完整网络架构第 4 节 eNSP 拓扑搭建

5.2 备赛策略

  1. 认证打底：考 HCIA-Datacom 认证，官方课程覆盖 90% 赛点。
  2. eNSP 练手：每天至少 1 小时敲命令，练到不看文档能默写 OSPF 全套配置。
  3. 背命令：interface → ip address → ospf → area → network → traffic-filter，这条链要形成肌肉记忆。
  4. 刷真题：华为官网有样题，限时模拟，培养时间感（正式比赛通常 2-4 小时）。
  5. 建错题本：反掩码写错、ACL 方向反了、忘记 save——把每个坑记下来，考前过一遍。

6. 考前验证清单

正式比赛前（或平时自测时），用这张清单确认"该会的都会了"：

  • ☐ eNSP 能正常启动，路由器双击能进命令行
  • ☐ 30 秒内能敲完"系统视图 → 接口视图 → 配 IP → 退出"全流程
  • ☐ 能默写静态路由命令：ip route-static + 目的网段 + 掩码 + 下一跳
  • ☐ 能默写 OSPF 五步：ospf 1 → router-id → area 0 → network → quit
  • ☐ 能配高级 ACL：acl 3000 → rule deny/permit → traffic-filter 应用到接口
  • ☐ 知道反掩码怎么算：掩码 255.255.255.0 → 反掩码 0.0.0.255
  • ☐ 知道 ACL 默认拒绝，忘记 permit ip 会把流量全断
  • ☐ 会用 display ip routing-table / display ospf peer brief 排查
  • ☐ 知道 save 保存配置，否则重启全丢
  • ☐ 了解考试时长与题型分配，有时间分配预案

免责声明：本章基于 B 站公开视频与华为 HCIA-Datacom 认证公开资料整理，具体比赛内容以华为 ICT 大赛组委会发布的最新通知与考试大纲为准。eNSP 命令示例在 eNSP V100R003C00 版本验证通过，不同版本命令可能略有差异。
